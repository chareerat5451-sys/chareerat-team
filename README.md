# ทีมวิจัยผู้เชี่ยวชาญ 15 ตำแหน่ง (เวอร์ชัน Netlify)

เว็บแอปทีม AI สำหรับงานวิจัย: โหมดอัตโนมัติ (สืบค้น → ร่าง → ตรวจ → แก้ซ้ำจนผ่าน), ส่งงานให้ผู้เชี่ยวชาญตรวจ, ระบบติดตามโครงการและจุดตรวจ

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `public/index.html` | หน้าเว็บทั้งหมด |
| `netlify/functions/data.mjs` | อ่านและบันทึกโครงการและผลตรวจใน Netlify Blobs (`/api/data`) |
| `netlify/functions/job.mjs` | รับงานและส่งผลงาน AI กลับให้หน้าเว็บ (`/api/job`) |
| `netlify/functions/files.mjs` | เก็บไฟล์ต้นฉบับและข้อความที่อ่านได้ (`/api/files`) |
| `netlify/functions/fetch.mjs` | เปิดลิงก์ หน้าเว็บ PDF Google Drive และคำบรรยาย YouTube (`/api/fetch`) |
| `netlify/functions/ai-background.mjs` | เรียก Claude API พร้อมการค้นหาเว็บ ทำงานเบื้องหลังได้นานสูงสุด 15 นาที |
| `netlify/lib/common.mjs` | ตรวจรหัสผ่าน เลือกโมเดล และเรียก Claude API |

## ขั้นตอนติดตั้ง

1. **สร้าง API key ของ Anthropic** ที่ https://console.anthropic.com เติมเครดิต และเปิดสิทธิ์ใช้การค้นหาเว็บ (Web search) ในการตั้งค่าของ Console
2. **อัปโหลดขึ้น GitHub** สร้าง repository แบบ Private แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ห้ามใส่รหัสผ่านหรือ API key ลงในไฟล์ใด ๆ)
3. **เชื่อม Netlify** ที่ https://app.netlify.com เลือก Add new project → Import an existing project → GitHub → เลือก repository นี้ ค่าการ build อ่านจาก `netlify.toml` อัตโนมัติ
4. **ตั้งค่า Environment variables** ที่ Project configuration → Environment variables

   | ชื่อ | ค่า | จำเป็น |
   | --- | --- | --- |
   | `ANTHROPIC_API_KEY` | API key จากข้อ 1 | จำเป็น |
   | `APP_PASSWORD` | รหัสผ่านเข้าใช้เว็บ | จำเป็น |
   | `OPENROUTER_API_KEY` | ใช้แทน `ANTHROPIC_API_KEY` ได้ (ดูหัวข้อ OpenRouter) | ใส่อย่างใดอย่างหนึ่ง |
   | `CLAUDE_MODEL_DEFAULT` | โมเดลหลัก (ค่าเริ่มต้น `claude-sonnet-5-5`) | ไม่บังคับ |
   | `CLAUDE_MODEL_COMPLEX` | โมเดลสำหรับระดับ L3 (ค่าเริ่มต้น `claude-opus-5-5`) | ไม่บังคับ |
   | `WEB_SEARCH_MAX_USES` | จำนวนครั้งค้นเว็บสูงสุดต่อคำขอ (ค่าเริ่มต้น 8) | ไม่บังคับ |
   | `WEB_SEARCH` | ใส่ `off` เพื่อปิดการค้นเว็บ | ไม่บังคับ |

5. **Deploy ใหม่** (Deploys → Trigger deploy) เพื่อให้ค่าตัวแปรมีผล แล้วเปิดเว็บและใส่รหัสผ่าน

## การเปิดไฟล์

- รองรับ Word (.docx), PDF, Excel (.xlsx .xls .ods .csv), PowerPoint (.pptx), ข้อความ (.txt .md .rtf .html .json) และรูปภาพ (.jpg .png .webp .gif)
- PDF ที่เป็นภาพสแกนและรูปภาพ ระบบส่งให้ Claude อ่านอัตโนมัติ สูงสุด 40 หน้าต่อไฟล์
- ไฟล์ .doc และ .ppt รุ่นเก่า ต้องบันทึกเป็น .docx / .pptx ก่อน
- ไฟล์ต้นฉบับที่เก็บในโครงการได้ ขนาดไม่เกิน 5.5 MB ต่อไฟล์ ไฟล์ใหญ่กว่านั้นเก็บเฉพาะข้อความ
- เปิดทั้งโฟลเดอร์ได้ (รวมโฟลเดอร์ย่อย) และแตกไฟล์ .zip ให้อัตโนมัติ ลากมาวางในช่องข้อความหรือส่วนไฟล์ของโครงการได้
- ตัวอ่านไฟล์โหลดจาก cdn.jsdelivr.net เมื่อใช้ครั้งแรก

## การเปิดลิงก์

- หน้าเว็บและบทความ: ดึงเนื้อหาหลัก ถ้าเป็นบทความวารสาร (เช่น ThaiJO) จะดึงข้อมูลบรรณานุกรมและเปิด PDF ฉบับเต็มให้อัตโนมัติ
- ลิงก์ไฟล์โดยตรง: PDF, Word, Excel, PowerPoint, รูปภาพ ไม่เกิน 5.5 MB
- Google Docs / Sheets / Slides / Drive: ต้องตั้งการแชร์เป็น "ทุกคนที่มีลิงก์ดูได้" ลิงก์โฟลเดอร์ Drive เปิดตรงไม่ได้ ให้ดาวน์โหลดเป็น .zip
- YouTube: ดึงคำบรรยาย (ภาษาไทยก่อน ถ้าไม่มีใช้ภาษาอังกฤษ) พร้อมเวลา ถ้าวิดีโอไม่มีคำบรรยาย หรือ YouTube ปิดกั้นการดึงจากเซิร์ฟเวอร์ จะแจ้งให้ทราบ
- หน้าที่ต้องล็อกอินเปิดไม่ได้

## ส่วนต่าง ๆ ของระบบ

- ภาพรวม: สถิติ งานใกล้กำหนดและเลยกำหนด งานค้าง ผลตรวจล่าสุด สำรองและกู้คืนข้อมูล
- โหมดอัตโนมัติ / ส่งงานให้ทีมตรวจ / โครงการและจุดตรวจ / ประวัติผลตรวจ / ทีม 15 ตำแหน่ง
- คลังแหล่งอ้างอิง: รวมแหล่งจาก D1 ผลตรวจ ไฟล์และลิงก์ในโครงการ เพิ่มเองหรือนำเข้า (DOI, BibTeX, RIS, รายการที่วาง) ตรวจยืนยันกับ Crossref ส่งออก APA 7 / รูปแบบไทย / Word / BibTeX / RIS และใช้ทีม AI เติมข้อมูล สรุปเป็นตารางสังเคราะห์ ตรวจรูปแบบ หาแหล่งที่ขาด
- ช่องค้นหาด้านบน: ค้นทุกอย่างในระบบ รวมเนื้อหาในไฟล์
- ส่งออก Word: ใช้ฟอนต์ TH SarabunPSK 16 pt กระดาษ A4

## คลังเอกสารฉบับเต็ม (ใหม่)

- เพิ่มเอกสารที่แท็บ "คลังแหล่งอ้างอิงและเอกสาร" (PDF, Word, PowerPoint, รูปภาพ, โฟลเดอร์, .zip) ระบบอ่านเนื้อหาเต็มพร้อมเลขหน้า เก็บต้นฉบับ ดึงบรรณานุกรม และสร้างบัตรสรุปอัตโนมัติ
- ไฟล์ PDF / Word / PowerPoint ที่เพิ่มในโครงการ เข้าคลังเอกสารอัตโนมัติ
- โหมดอัตโนมัติ "ใช้เฉพาะเอกสารในคลัง": ผู้ร่างเขียนจากข้อความในเอกสารเท่านั้น อ้างอิง APA พร้อมเลขหน้า ทุกการอ้างอิงกดดูข้อความต้นฉบับได้ ระบบสร้างรายการอ้างอิงจากเอกสารที่ใช้จริง และตรวจรหัสอ้างอิงที่ไม่มีอยู่จริงและเลขหน้า จุดที่ไม่มีหลักฐานจะเป็น [ต้องเพิ่มเอกสาร: …]
- เลขหน้าที่อ้าง: ระบบแปลงเลขหน้า PDF เป็นเลขหน้าที่พิมพ์ในวารสารให้อัตโนมัติเมื่อทราบช่วงหน้า แก้เองได้ที่ "บัตรสรุป"
- ค้นในเนื้อหาเอกสารทั้งหมด และส่งออก "ชุดความรู้" (.md) ไปใส่ใน Claude Project ได้

## แก้งานต่อและทำความสะอาดคลัง (ใหม่)

- งานจากโหมดอัตโนมัติมีส่วน "เพิ่มข้อมูลและแก้งานต่อ": แนบเอกสารตรงจุด [ต้องเพิ่มเอกสาร: …], กรอกข้อมูลจุด [ต้องเติม: …], พิมพ์คำสั่งแก้เพิ่มเติม แล้วกด "แก้งานต่อ" ระบบแก้ทั้งงานและตรวจซ้ำจนผ่าน บันทึกเป็นฉบับใหม่ (ฉบับเดิมยังอยู่ในประวัติ)
- เมื่อเพิ่มเอกสารใหม่เข้าคลัง ระบบตรวจว่าช่วยเติมงานที่ค้างได้หรือไม่ แล้วแจ้งที่หน้าภาพรวม
- คลังเก็บเฉพาะรายการที่มีไฟล์เอกสาร รายการซ้ำถูกรวมอัตโนมัติ รายการที่ไม่มีไฟล์ถูกย้ายไปถังขยะ (กู้คืนได้ภายใน 30 วัน แล้วลบถาวร)

## วนตรวจและแก้จนผ่าน (ใหม่)

- โหมดอัตโนมัติ แก้งานต่อ และแท็บส่งงานให้ทีมตรวจ วนตรวจและแก้ไม่จำกัดรอบจนผ่านเกณฑ์ทุกตำแหน่ง หยุดได้ด้วยปุ่ม "หยุด" (เลือกจำนวนรอบคงที่ได้ในโหมดอัตโนมัติ)
- เกณฑ์ผ่านรวมการตรวจการอ้างอิงอัตโนมัติ: รหัสแหล่งที่ไม่มีในคลังและเลขหน้าที่ไม่ตรงต้นฉบับต้องถูกแก้ก่อน
- ถ้าเหลือเฉพาะประเด็นที่ต้องใช้ข้อมูลจริง (ผู้ตรวจระบุ needsData) ระบบหยุดทันทีและแจ้งให้เพิ่มข้อมูล เมื่อเพิ่มแล้วกดวนแก้ต่อ
- แท็บส่งงานให้ทีมตรวจ: ติ๊ก "ให้ทีมแก้งานต่อจนผ่านเกณฑ์" ทีมจะแก้งานของผู้วิจัยและแสดง "งานที่ทีมแก้แล้ว" พร้อมคะแนนรายรอบ คัดลอกหรือส่งออก Word ได้

## วนตรวจและแก้จนผ่าน (ใหม่)

- ใช้ในโหมดอัตโนมัติ การแก้งานต่อ และแท็บส่งงานให้ทีมตรวจ (ติ๊ก "ให้ทีมแก้งานต่อจนผ่านเกณฑ์" ไว้เป็นค่าเริ่มต้น)
- ไม่จำกัดจำนวนรอบ ถ้าคะแนนไม่ดีขึ้น 3 รอบติดกัน ระบบเปลี่ยนวิธีแก้อัตโนมัติ 4 ขั้น: (1) แก้ตามความเห็นผู้ตรวจ (2) A1 วิเคราะห์สาเหตุแล้วแก้ทีละประเด็น (3) ใช้โมเดลที่คิดละเอียดที่สุด (4) เรียบเรียงใหม่ทั้งฉบับ
- จำฉบับที่ดีที่สุดเสมอ ถ้าฉบับใหม่แย่ลง ระบบเริ่มแก้จากฉบับที่ดีที่สุด และส่งมอบฉบับที่ดีที่สุดเมื่อหยุด
- หยุดเมื่อ: ผ่านเกณฑ์ทุกตำแหน่ง / เหลือเฉพาะจุดที่ต้องใช้ข้อมูลจริง / ลองครบ 4 วิธีแล้วคะแนนไม่ดีขึ้น (แสดงผลวิเคราะห์ของ A1) / กดปุ่ม "หยุด"
- บันทึกความคืบหน้าทุกรอบ ถ้าปิดหน้าเว็บระหว่างทำงาน งานจะขึ้นสถานะ "หยุดกลางคัน" ในหน้าภาพรวม กด "แก้งานต่อ" เพื่อวนต่อจากฉบับที่ดีที่สุด
- ระบบทำงานเฉพาะขณะเปิดหน้าเว็บ
- `CLAUDE_PROJECT_INSTRUCTIONS.md` คือชุดคำสั่งสำหรับ Claude Project ฉบับวนจนผ่าน

## ทีม D สืบค้นแหล่งที่ขาดและโหลดเอกสารเข้าคลัง (ใหม่)

เปิดไว้เป็นค่าเริ่มต้นในโหมดอัตโนมัติ (ช่อง "ให้ทีม D สืบค้นแหล่งที่ขาด…")

1. เมื่อวนแก้จบแล้วงานยังมีจุด [ต้องเพิ่มเอกสาร: …] หรือ [อ้างอิง: …] หรือผู้ตรวจบอกว่าต้องใช้เอกสารเพิ่ม D1 จะค้นเว็บ (ไทยและอังกฤษ ตั้งแต่ 10 ปีล่าสุด ไม่เกิน 5 เรื่องต่อจุด รับเอกสารทุกประเภท)
2. D2 ตัดรายการที่เก่าเกิน ซ้ำ หรือไม่มีลิงก์ และตรวจ DOI กับ Crossref
3. ระบบโหลดไฟล์เข้าคลังเอกสาร (ถ้าหน้าบทความมี PDF ฉบับเต็มจะโหลด PDF ถ้าไม่มีจะเก็บข้อความหน้าเว็บหรือบทคัดย่อ) แล้วสร้างบัตรสรุป
4. ระบบแก้งานต่อเป็นฉบับใหม่โดยใช้เอกสารที่โหลด และวนตรวจจนผ่าน ทำซ้ำได้สูงสุด 5 รอบสืบค้นต่อชิ้นงาน และหยุดเมื่อไม่พบเอกสารใหม่
5. ถ้าเลือก "ใช้เฉพาะเอกสารในคลัง" แต่คลังยังไม่มีเอกสาร ทีม D จะสืบค้นและโหลดเอกสารให้ก่อนเริ่มร่าง

เอกสารที่ต้องล็อกอินหรือเสียค่าใช้จ่ายจะโหลดไม่ได้ ระบบจะแสดงรายการพร้อมลิงก์ให้ดาวน์โหลดเองแล้วแนบที่จุดที่ขาด ในแท็บคลังแหล่งอ้างอิง ปุ่ม "AI หาแหล่งที่ขาด" มีปุ่ม "ให้ทีม D โหลดทุกรายการเข้าคลัง" ด้วย ตรวจเอกสารที่โหลดทุกเรื่องก่อนใช้จริง

## แท็บทีม D สืบค้น (ใหม่)

พิมพ์หัวข้อหรือชื่องานวิจัย แล้วกด "ให้ทีม D สืบค้น" ทีม D จะหาบทความ งานวิจัย หนังสือ ตำรา สื่อ และเว็บหน่วยงาน ทั้งไทยและอังกฤษ ย้อนหลัง 5 ปี ครั้งละไม่เกิน 10 รายการ พร้อมหัวข้อที่เกี่ยวข้องและคำค้น
- D2 ตัดรายการที่เก่าเกิน 5 ปีหรือซ้ำ และตรวจ DOI กับ Crossref
- ติ๊กเลือกแล้วกด "โหลดที่เลือกเข้าคลัง" หรือ "ดาวน์โหลดที่เลือกลงเครื่อง" หนังสือที่ไม่มีฉบับฟรีจะมีเฉพาะลิงก์
- กด "ค้นหัวข้อนี้ต่อ" เพื่อค้นหัวข้อที่เกี่ยวข้อง ผลการค้นครั้งล่าสุดจะเก็บไว้แม้ปิดหน้าเว็บ
- เวอร์ชัน claude.ai ค้นเว็บไม่ได้ จะเสนอหัวข้อ คำค้น และลิงก์ค้นหาแทน ดาวน์โหลดเองแล้วลากไฟล์มาวางเพื่อเข้าคลัง

## ใช้ AI ผ่าน OpenRouter (กรณีจ่ายเงินที่ Anthropic ไม่ได้)

ระบบรองรับคีย์ 2 แบบ ใส่แบบใดแบบหนึ่ง ได้โมเดล Claude ชุดเดียวกัน
- `ANTHROPIC_API_KEY` จาก platform.claude.com
- `OPENROUTER_API_KEY` จาก openrouter.ai (จ่ายด้วยบัตรผ่านระบบของ OpenRouter, AliPay หรือคริปโต)

วิธีตั้งค่า OpenRouter
1. สมัครที่ openrouter.ai แล้วไปที่ Settings > Credits เติมเครดิต (มีค่าธรรมเนียมการเติมเล็กน้อย)
2. ไปที่ Settings > API Keys สร้างคีย์ (ตั้งวงเงินคีย์ได้) แล้วคัดลอกคีย์ที่ขึ้นต้นด้วย `sk-or-`
3. ใน Netlify: Project configuration > Environment variables เพิ่ม Key `OPENROUTER_API_KEY` วางคีย์ใน Value
4. Deploys > Trigger deploy แล้วเข้าเว็บ มุมบนจะแสดง "AI: Claude ผ่าน OpenRouter"

ถ้าใส่ทั้งสองคีย์ ระบบใช้ Anthropic ก่อน บังคับใช้ OpenRouter ได้โดยเพิ่ม `AI_PROVIDER` = `openrouter` เปลี่ยนรุ่นโมเดลได้ด้วย `OPENROUTER_MODEL_DEFAULT` และ `OPENROUTER_MODEL_COMPLEX` (ค่าเริ่มต้น anthropic/claude-sonnet-5.5 และ anthropic/claude-opus-5.5) การค้นเว็บของทีม D ใช้ปลั๊กอินค้นเว็บของ OpenRouter ซึ่งคิดค่าใช้จ่ายเพิ่มต่อครั้ง

## เข้าใช้งานไม่ได้ (รหัสผ่านไม่ผ่าน)

หน้าเข้าสู่ระบบจะบอกสาเหตุเอง:
- "รหัสผ่านไม่ถูกต้อง": ต้องตรงกับค่า `APP_PASSWORD` ใน Netlify ทุกตัวอักษร ตัวพิมพ์ใหญ่-เล็กต้องตรง (ช่องว่างหน้า-หลัง และช่องว่างซ้ำ ระบบตัดให้เอง) ติ๊ก "แสดงรหัสผ่าน" เพื่อดูสิ่งที่พิมพ์ ถ้าขึ้นเตือนว่ามีตัวอักษรไทย ให้สลับแป้นเป็นภาษาอังกฤษ
- "ยังไม่ได้ตั้งรหัสผ่านใน Netlify": เพิ่ม `APP_PASSWORD` (Scopes: All scopes) แล้วกด Deploys > Trigger deploy
- "ไม่พบฟังก์ชันบนเซิร์ฟเวอร์": อัปโหลดโฟลเดอร์ `netlify` และไฟล์ `netlify.toml`, `package.json` ขึ้น GitHub ไม่ครบ
- หลังเข้าได้ ถ้ามีแถบเตือน ANTHROPIC_API_KEY ให้เพิ่มคีย์ใน Environment variables แล้ว deploy ใหม่

ทุกครั้งที่แก้ Environment variables ต้อง deploy ใหม่ ค่าใหม่จึงจะมีผล

## การเก็บข้อมูล

- โครงการและผลตรวจเก็บใน Netlify Blobs ชื่อ `research-team` ของเว็บไซต์นี้ เปิดจากเครื่องไหนก็เห็นข้อมูลเดียวกัน
- ไฟล์ในโครงการเก็บในคีย์ `files/` (ต้นฉบับ) และ `filetext/` (ข้อความที่อ่านได้)
- งาน AI ที่กำลังทำเก็บชั่วคราวในคีย์ `jobs/` และถูกลบเมื่อหน้าเว็บรับผลแล้ว
- คลังแหล่งอ้างอิงเก็บในคีย์ `library/` แยกรายการละหนึ่งคีย์ เอกสารฉบับเต็มเก็บต้นฉบับใน `files/` และเนื้อหาแยกหน้าใน `filetext/`
- ย้ายข้อมูลจากเวอร์ชัน claude.ai: กด "สำรองข้อมูล" ในเวอร์ชัน claude.ai แล้วกด "กู้คืนจากไฟล์" ในเวอร์ชันนี้ (ไฟล์ในโครงการจะถูกสร้างใหม่เป็นข้อความ)

## ค่าใช้จ่าย

- Netlify: ใช้แพ็กเกจฟรีได้ ถ้า Background Functions ใช้ไม่ได้ในแพ็กเกจของบัญชี หน้าเว็บจะแจ้งว่า "ไม่พบงานบนเซิร์ฟเวอร์"
- Anthropic: คิดตามจำนวนข้อความที่ส่งและรับ และคิดเพิ่มต่อการค้นเว็บ ดูราคาและตั้งวงเงินสูงสุดได้ใน Console

## ความปลอดภัย

- รหัสผ่านและ API key อยู่ใน Environment variables ของ Netlify เท่านั้น ไม่อยู่ในโค้ดหรือ GitHub
- ทุกคำขอไปยังเซิร์ฟเวอร์ต้องมีรหัสผ่านถูกต้อง เปลี่ยนรหัสผ่านได้โดยแก้ `APP_PASSWORD` แล้ว deploy ใหม่
- ควรตั้งวงเงินใช้จ่ายรายเดือนใน Anthropic Console ป้องกันค่าใช้จ่ายเกินคาด

## รายการตรวจหลังติดตั้ง (ใช้เวลาประมาณ 10 นาที)

1. เปิดเว็บ ใส่รหัสผ่าน หน้าภาพรวมต้องขึ้น
2. คลังแหล่งอ้างอิง → นำเข้า → วาง DOI `10.1037/0003-066X.59.1.29` → ต้องได้ข้อมูลครบและสถานะ "ยืนยันแล้ว" (ทดสอบ Crossref)
3. โหมดอัตโนมัติ → พิมพ์ความต้องการสั้น ๆ → เริ่มทำงาน → ต้องเห็นบันทึกการทำงานไล่ทีละขั้นจนได้งานฉบับล่าสุด (ทดสอบ Claude API, การค้นเว็บ และ Background Functions)
4. แท็บคลังแหล่งอ้างอิงและเอกสาร → เลือกไฟล์เอกสาร PDF 1 ไฟล์ → ต้องได้บรรณานุกรมและบัตรสรุป → กด "อ่านเอกสาร" ต้องเห็นเนื้อหาแยกหน้า
4.1 โหมดอัตโนมัติ → แหล่งข้อมูล "ใช้เฉพาะเอกสารในคลัง" → งานที่ได้ต้องมีรหัส S กดดูต้นฉบับได้ และมีรายการอ้างอิงท้ายงาน
5. วางลิงก์บทความ ThaiJO 1 ลิงก์ → เปิดลิงก์ (ทดสอบการดึงลิงก์)
6. ภาพรวม → สำรองข้อมูล → ต้องได้ไฟล์ .json

ถ้าข้อใดไม่ผ่าน คัดลอกข้อความแจ้งเตือนบนหน้าจอ และดู Netlify → Logs → Functions
